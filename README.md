# Bitcoiners(Working Title)

![bitcoiners](https://github.com/Marc26z/bitcoiners/blob/main/assets/Bitcoiners.png?raw=true)

The purpose of this book is to teach people what bitcoin is, how to create your own keys, use the lightning network and basically use bitcoin as p2p ecash instead of another Wallstreet sex doll. Bitcoiners is the working title, but I am considering changing it to Buy This Book With Bitcoin: How to Use Bitcoin as Peer-To-Peer Electronic Cash. So far, I have three rought chapters done. The first one is publised on nostr. I want to keep it open source and available for free, but I also want to publish the book and sell it for sats. My goal is to teach people how to be Independent authors who sell books, soap, and other stuff for bitcoin. There are some services that allow authors to do this, but I want to make it accessible to everybody. I'm writing this book to have someting to sell on my BTCpayServer and Hopefully teach others how to do the same.
